# Papertrail · 학회 일정 모음

이미지에 있던 AI, Robotics, Autonomous Driving 학회·저널 17개를 모아 보는 웹사이트입니다. 공식 출처에서 확인한 일정만 사용하며, 미발표 날짜는 빈 상태로 유지합니다. 2027년 학회들과 ICRA·ICLR·AAAI·ECCV 2028년 회차를 추적합니다. 새 회차가 되면 `data/seed.json`에서 연도와 출처를 갱신해야 합니다.

## 공개 사이트

GitHub Pages 정적 배포와 매시간 공식 출처 확인을 지원합니다. 배포 및 예약 실행 제한은 [DEPLOY.md](DEPLOY.md)를 참고하세요.

## 실행

Node.js 22 이상(권장 24)이 필요합니다. 외부 npm 패키지가 없어 설치 단계가 없습니다.

Windows에서는 **`start.cmd`를 더블클릭**하면 서버와 브라우저가 열립니다. 이미 실행 중인 Papertrail 서버가 있으면 그 사이트를 엽니다. 새로 시작한 서버의 터미널 창을 열어 두어야 자동 갱신이 계속됩니다.

```powershell
cd 'C:\Users\LEEJUNSEOK\Desktop\Paper'
npm.cmd start
```

브라우저에서 **http://127.0.0.1:3000** 을 엽니다. macOS/Linux에서는 `npm start`를 사용합니다. 개발 시 `npm.cmd run dev`로 서버 코드 변경을 자동 재시작할 수 있습니다.

```powershell
npm.cmd test       # 날짜/시간대, 캐시, 실패 복구, ICS, HTTP 보안 테스트
npm.cmd run sync   # 공식 출처 한 번 확인 후 캐시 저장
npm.cmd run test:browser # 실행 중인 서버를 Chrome에서 검증 (별도 임시 프로필)
```

## 자동 갱신의 범위

- 서버를 시작하면 공식 출처를 확인하고, 완료 후 기본 60분마다 다시 확인합니다. 서버 프로세스와 인터넷 연결이 유지되어야 합니다. 페이지를 닫아도 서버가 실행 중이면 계속 갱신합니다.
- ICLR, CVPR, AAAI, ICRA, IROS, IV의 현재 공식 페이지는 명시된 날짜를 자동으로 해석합니다. 공식 UTC 카운트다운, AoE, PST를 보존하며 시각이 없는 공지는 날짜만 저장합니다.
- 그 외 출처와 저널 안내는 페이지 본문 변경을 감지합니다. 날짜를 안전하게 해석하지 못한 변경은 **원문 검토 필요**로 표시하고 기존 값을 보존합니다. 모든 사이트의 공지를 무조건 해석하는 기능은 아닙니다.
- 브라우저는 서버 상태를 주기적으로 다시 읽습니다. **실시간 푸시가 아니라 주기적 확인**이며, 수동 새로고침도 가능합니다. 연속 수동 요청은 30초 간격으로 제한하고 중복 수집을 방지합니다.
- 출처가 차단되거나 응답하지 않으면 마지막 데이터를 계속 표시하고 실패를 공개합니다. 실제 검증 시 Science Robotics는 HTTP 403, TPAMI는 자동 접근 제한이 있었습니다.
- `sourceCheckedAt`는 접근 확인 시각이고 `verifiedAt`는 명시된 날짜를 해석했거나 초기 자료를 수동 확인한 시각입니다. `autoUpdatedFields`에 이번 수집에서 확인한 필드가 기록됩니다. 해당 시각이 모든 일정 항목의 재검증을 뜻하지는 않습니다.
- 논문 등록/초록 마감과 본문 마감은 구분합니다. 저널의 일반 투고는 상시 접수로 표시하며 특집호·학회 연계 프로그램의 개별 마감까지 포함하지 않습니다.

공식 사이트가 문서 구조를 바꾸면 `lib/parsers.mjs`의 파서를 수정해야 할 수 있습니다. 초기 자료와 출처 메모는 `data/seed.json`, `data/research-notes.md`에 있습니다. 출처 URL을 바꾸거나 더 최신 `verifiedAt`로 초기 자료를 검증하면 오래된 캐시보다 새 초기 자료가 우선합니다.

## 계속 운영하기

개인 PC에서 실행하면 PC 종료/절전 시 갱신도 멈춥니다. 공개 운영에는 Node.js 프로세스를 계속 실행할 서버 또는 Docker 호스팅이 필요합니다. 정적 파일만 올리는 호스팅으로는 이 수집 서버가 실행되지 않습니다. 아래 설정은 배포 준비이며, 공개 서버 배포 자체는 수행하지 않았습니다.

```sh
docker build -t paper-tracker .
docker run -d --name paper-tracker --restart unless-stopped \
  -p 3000:3000 -v paper-data:/app/storage paper-tracker
```

Windows PowerShell에서는 `docker run` 명령을 한 줄로 입력합니다. 볼륨은 마지막 성공 일정과 출처 상태를 재시작 후에도 보존합니다. 공개 도메인을 연결할 때 HTTPS를 제공하는 역방향 프록시를 앞에 두고 `PUBLIC_ORIGIN=https://your-domain.example`을 설정합니다. 외부 서버나 계정 생성은 필요할 때 별도로 진행합니다.

| 환경 변수 | 기본값 | 의미 |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | 로컬 바인딩. 외부/Docker 접근은 `0.0.0.0` |
| `PORT` | `3000` | HTTP 포트 |
| `SYNC_INTERVAL_MINUTES` | `60` | 완료 후 다음 확인 간격. 최소 5분, 최대 1440분 |
| `DATA_DIR` | 프로젝트의 `data` | `cache.json` 저장 경로 |
| `PUBLIC_ORIGIN` | 요청의 호스트 | 공개 배포 시 허용할 정확한 브라우저 Origin |
| `DISABLE_AUTO_SYNC` | 설정 안 함 | `1`이면 자동 수집 없이 저장 데이터를 사용. 수동 확인은 가능 |

예를 들어 PowerShell에서 포트를 바꾸려면 `$env:PORT='3010'` 설정 후 `npm.cmd start`를 실행합니다.

## API와 캘린더

- `GET /api/conferences`: 일정 목록, 최근 시도/성공 시각, 다음 확인 시각, 출처별 상태.
- `POST /api/refresh`: 비동기 수동 수집 시작(HTTP 202). 브라우저는 같은 Origin에서만 허용하며 CLI 호출은 `X-Paper-Refresh: 1` 헤더가 필요합니다.
- `GET /api/calendar.ics`: 알려진 초록/등록 마감, 논문 마감, 개최 기간. `?ids=iclr-2027,cvpr-2027`로 특정 일정만 선택할 수 있습니다.
- `GET /api/health`: 서버 생존 상태와 수집 상태.

ICS를 내려받아 가져오기 하면 그 시점의 복사본입니다. 지속 갱신이 필요하면 외부에서 접근 가능한 `/api/calendar.ics` URL을 캘린더 앱에 **URL 구독**으로 추가합니다. 구독 재확인 간격은 캘린더 제공자가 결정합니다. 날짜만 발표된 마감은 종일 일정, 시각이 발표된 마감은 정확한 UTC 시각, 개최 기간은 종료일 포함으로 내보냅니다. 미정·상시 투고에는 가상의 마감 일정을 만들지 않습니다.

## 구성

상단 카운트다운은 아래 목록에서 선택한 학회의 Submission Deadline을 표시합니다. 학회명을 누르면 하나만 선택되고 밑줄로 구분됩니다. 선택은 브라우저에 저장되며 새로고침·자동 갱신·필터 변경으로 다른 학회로 바뀌지 않습니다. 미정·상시 투고·마감된 항목은 해당 상태를 표시합니다. 상세 일정은 학회명 옆 정보 아이콘으로 엽니다.

개최 일정 오른쪽의 `과거 Acceptance Rate`는 확인한 과거 회차의 공개 통계입니다. 비율·연도·트랙을 함께 표시하고 숫자를 클릭하면 출처가 열립니다. 학회 상세 화면에는 집계 논문 수(확인된 경우), 출처 기관과 확인일을 표시합니다. 학회 공식 자료 및 연구기관 공식 보고를 구분하며, 미확인 통계는 추정하지 않습니다. 이 자료는 `data/seed.json`의 `acceptanceHistory`에서 관리하며, 마감일 수집 작업이 채택률까지 자동 갱신하지는 않습니다. 현재 회차의 예상 채택률이나 최신 회차 통계라는 의미는 아닙니다.

화면은 분야·연도·상태별 필터, 검색, 브라우저에 저장되는 즐겨찾기, 월별 캘린더, KST/AoE/UTC 전환을 제공합니다. 모바일에서는 마감일과 개최일을 가로 스크롤 없이 읽을 수 있습니다. 마감 당일은 D-DAY로 표시합니다. 메일·메신저 알림은 포함하지 않습니다.

브라우저 검증 결과와 데스크톱·모바일 스크린샷은 `artifacts/`에 저장됩니다. 일반 실행에는 Chrome이 필요하지 않으며, 자동 브라우저 검사만 Chrome/Chromium이 필요합니다.

`server.mjs`는 Node 네이티브 HTTP/API/정적 파일 서버, `lib/sync.mjs`는 시간 제한·최대 동시 3개 출처 수집과 캐시, `lib/parsers.mjs`는 공식 문서 파서, `lib/calendar.mjs`는 UTF-8 ICS 생성기입니다. `public/`에는 빌드 과정 없이 실행되는 프런트엔드가 있습니다. 테스트는 네트워크와 무관하게 고정 문서와 가짜 응답으로 실행합니다.
